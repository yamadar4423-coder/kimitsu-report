# 気密測定 報告書ツール（Web版）

JIS A 2201 準拠の気密測定（C値）まわりを、スマホ／PCのブラウザだけで回すためのツールです。

## ページ
- **現場用**（`report.html`）— 現場でΔP・Qを入力し、C値・n・R²・合否をその場で確認。良い回（最大3件）を選んで「データをコピー」→ LINE等で送信。
- **事務所用**（`office.html`）— 受け取ったデータを貼り付け、面積などの設計情報と写真を追加して、報告書用データ（JSON）を作成。物件プロファイルを保存すると次回から設計情報を自動反映。

## GitHub Pages
`index.html` から各ページへリンクしています。スマホではこのページのURLを開いてください。

## メモ
- すべてブラウザ内で処理し、データを外部送信しません。
- 事務所用で作ったデータから実際の報告書（Excel/PDF）を生成する部分は、Excelを使うPC側ツールで行います（このリポジトリには含みません）。
- このリポジトリには顧客データ・報告書テンプレートは含めていません。
